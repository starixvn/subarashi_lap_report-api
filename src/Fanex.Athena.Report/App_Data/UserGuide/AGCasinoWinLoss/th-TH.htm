ข้อมูลทั่วไป

  • รายงานสรุปผลแพ้ชนะรายวันใน Agคาสิโน.
  • รายงานนี้สนับสนุนข้อมูลล่าสุด คุณสามารถกรองข้อมูลได้สูงสุด 3 เดือนต่อการค้นหา.
  • หลังเวลา 3:30(GMT-4) รายงานถึงจะแสดงข้อมูลของเมื่อวาน
  • OANDA Exchange Service จะใช้อัตราแลกเปลี่ยนในวันสุดท้ายของแต่ละเดือนที่เลือกเมื่อแปลงตัวเลข.

ตัวกรองการค้นหา

  • สกุลเงิน: เลือกสกุลเงินที่จะดึงข้อมูล.
    • ทั้งหมด: สกุลเงินที่รองรับทั้งหมดจะแสดงออกมา.
  • สกุลเงินฐาน: แปลงข้อมูลทั้งหมดเป็นสกุลเงินฐานเพื่ออ้างอิงเท่านั้น
  • ไม่รวมข้อมูลการทดสอบ: ไม่รวมตั๋วทั้งหมดจากบัญชีทดสอบ.

ตัวชี้การรายงาน

  • สกุลเงิน: ผู้ใช้เลือกสกุลเงินที่เสนอให้แล้ว.
  • เทิร์นโอเวอร์: เทิร์นโอเวอร์ของลูกค้าภายในช่วงวันที่ที่เลือก.
  • ธุรกรรมทั้งหมด: ตั๋วเดิมพันทั้งหมดของผลิตภัณฑ์ที่เลือก.
  • ซ่อนผู้เล่น W/L: (WL/ Comm/ รวม) ผลกระทบ รายงานการหมุนเวียนเท่านั้น.
  • ผู้ได้รับอนุญาต:
    • W/L: จำนวนเงินที่ชนะหรือสูญเสียของผู้รับใบอนุญาตโดยขึ้นอยู่กับตั๋วเดิมพันของผู้เล่น.
    • ส่วนร่วม: จำนวนที่ผู้รับใบอนุญาตมีส่วนร่วม.
    • โปรโมชั่น: จำนวนเงินที่เจ้ามือจะล่วงหน้าเพื่อชำระให้แก่ผู้เล่นที่ชนะโปรโมชั่น.
    • เงินรางวัลแจ็คพอต: จำนวนเงินที่ผู้รับใบอนุญาตจะล่วงหน้าในการชำระเงินให้แก่ผู้เล่นที่ชนะเงินรางวัลแจ็คพอต.
    • รวม: จำนวนเงินที่เหลือของผู้รับใบอนุญาตหลังจากการสนับสนุนแล้วแพ้กัน.

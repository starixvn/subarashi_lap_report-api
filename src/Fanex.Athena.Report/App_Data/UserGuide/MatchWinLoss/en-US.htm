General Info

  • This report contains only won/lost/draw tickets.
  • Data is available from {balance-up-date}.
  • Data can be filtered by Currency and Product.
  • System displays matches for selected products and groups them by leagues.
  • A red negative number indicates a loss for Licensee whereas the black positive indicates a win.
  • Data win loss for Parlay and Outright tickets will not be counted for each match in the main report but will be summarized in the separate area at the bottom of the report.
  • Clicking on match name of Sportsbook product will show all tickets of the match. This behavior does not apply to other products.
  • OANDA Exchange Service will use the exchange rate of the end date of each selected month when converting the figures.

Search Filters

  • Currency: selects the currency which data will be retrieved.
    • All: all supported currencies will be listed out.
  • Base Currency: Convert all data to base currency for reference only.
  • Product: selects the Product type which data will be retrieved.
    Note that the report will be modified (some columns will be hidden/showed) bases on the number of supported Product.

Report Guidelines

  • Match: displays the match detail information as formatted: home team (top) and away team. By click on each match for the match’s detail information.
  • Turnover: total Customer turnover within a selected date range.
  • Total Transaction: total bet tickets of each selected products.
  • Customer W/L:
    • Win Loss: the amount customer won or lost based on their bets.
    • Comm: total commission counted on bet tickets.
    • Total: Total win/loss amount including commission.
      Total = Win/Loss + Commission
  • Licensee W/L: the win loss amount Licensee has settled with Customer.
    Licensee Win/Loss = – (Customer Win/Loss)

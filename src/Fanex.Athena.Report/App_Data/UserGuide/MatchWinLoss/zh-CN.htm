一般信息

  • 本报告仅包含赢/输/和局的票。
  • 数据可从{balance-up-date}查看。
  • 可按货币和产品过滤数据。
  • 系统会显示选定产品的赛事，并按联赛类别将其分组。
  • 红色的负数表示承租公司的损失，而黑色的正数表示赢得的收入。
  • 主报告中不会计入混合过关和优胜冠军的输赢数据，但会在报告底部的单独区块中被归纳总结。
  • OANDA 匯率換算服務將會使用所選擇當月最後一天的匯率來轉換數值。

搜索过滤器

  • 货币:以货币來选择所会列出的数据。
    • 全部:列出所有支持的货币。
  • 基础货币：将所有资料转换为基础货币但仅供参考。
  • 产品:选择要检索的产品类型。
    注意，报告会根据支持产品的数量而变动（某些列会被隐藏/显示）。

报告指南

  • 赛事:显示赛事详细信息，格式为：主队（在上）和客队。点击不同赛事可显示每场赛事的详细信息。
  • 交易额: 选定的日期范围内的会员总交易额。
  • 总交易数:选定产品的投注票总量。
  • 会员输赢:
    • 输赢: 会员下票的输赢金额。
    • 佣金: 每张票所计算的总佣金金额。
    • 总和: 总输赢金额含佣金。
      总和 = 总输赢金额 + 佣金。
  • 承租公司输赢： 承租公司已与会员结算的输赢金额。
    承租公司输赢= - (会员输赢)

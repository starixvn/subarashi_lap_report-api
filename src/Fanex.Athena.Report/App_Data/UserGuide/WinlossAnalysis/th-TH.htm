ข้อมูลทั่วไป

  • รายงานจะมีเฉพาะตั๋วที่ชนะ/แพ้/เสมอเท่านั้น.
  • ตัวเลขที่เป็นลบสีแดงหมายถึงผู้ได้รับอนุญาตแพ้ ส่วนตัวเลขที่เป็นบวกสีดำหมายถึงการชนะ.
  • OANDA Exchange Service จะใช้อัตราแลกเปลี่ยนในวันสุดท้ายของแต่ละเดือนที่เลือกเมื่อแปลงตัวเลข.
  • รายงานนี้มีสองโหมดคือ วันที่และเวลา เพื่อตอบสนองตัวเลือกการดูที่ผู้ใช้ต้องการ.
    • วันที่การเงิน:
      • ข้อมูลจะคำนวณตามวันที่การเงินของตั๋ว.
      • รายงานนี้สนับสนุนข้อมูลล่าสุด คุณสามารถกรองข้อมูลได้สูงสุด 3 เดือนต่อการค้นหา.
    • เวลาเคลียร์:
      • ข้อมูลจะคำนวณตามเวลาเคลียร์ของตั๋ว หลีกเลี่ยงการเปรียบเทียบข้อมูลนี้กับฟังก์ชันอื่น ๆ ของ LAP เนื่องจากคำนวณในช่วงเวลาที่แตกต่างกัน.
      • รายงานนี้สนับสนุนข้อมูลที่ทันสมัย คุณสามารถกรองข้อมูลได้สูงสุด 1 เดือนต่อการสืบค้น.
  • ตั๋ว 'Extra Payout' จะถูกแยกออกจากรายงานนี้เมื่อดูภายในช่วงวันที่ที่เลือก.

ตัวกรองการค้นหา

  • นที่: รับข้อมูลที่สอดคล้องตามโหมดวันที่การเงินหรือโหมดเวลาการชำระเงินที่ผู้ใช้เลือก.
  • ชั่วโมง: แสดงเมื่อเลือกโหมดเวลาการชำระเงิน.
  • ผลิตภัณฑ์: เลือกประเภทของตั๋วเดิมพัน.
    • ถ้าถูกเลือก Sportsbook: ตัวกรองกีฬาจะแสดง Parlay และ Saba Virtual Sports แยกกัน.
    • หากเลือกโหมดเวลาการชำระเงิน รายการผลิตภัณฑ์จะรองรับเฉพาะ Sportsbook, Virtual Sports และ Number Game เท่านั้น.
  • กีฬา, ประเภทการเดิมพัน: เลือกประเภทกีฬา, ประเภทการเดิมพันของตั๋วเดิมพัน.
  • แพลตฟอร์ม: แพลตฟอร์มที่ผู้เล่นใช้ในการวางเดิมพัน.
  • สถานะ: เลือกสถานะของตั๋วเดิมพัน.
  • สถานะสด: ใช้ตัวกรอง "สด" เพื่อดึงข้อมูลตั๋วที่สดหรือไม่สด.
    • โปรดทราบว่าสถานะ Mix Live & Non-Live ถูกใช้สำหรับตั๋ว Parlay.
  • สกุลเงิน: เลือกสกุลเงินที่จะดึงข้อมูล.
    • ทั้งหมด: สกุลเงินที่รองรับทั้งหมดจะแสดงออกมา.
  • สกุลเงินฐาน: แปลงข้อมูลทั้งหมดเป็นสกุลเงินฐานเพื่ออ้างอิงเท่านั้น
    • {PlayerSegmentation_VIPManagement-permission-section}
  • สำหรับผู้เล่น VIP เท่านั้น: เลือกประเภทผู้เล่นที่จะดึงข้อมูล เลือก "ไม่" เพื่อดูผู้เล่นทั้งหมด
    • {/PlayerSegmentation_VIPManagement-permission-section}
  • ระดับความเสี่ยง: เลือกประเภทระดับความเสี่ยงที่จะดึงข้อมูลออกมา.
  • Odds Group: เลือกประเภทกลุ่มอัตราต่อรองที่จะดึงข้อมูลออกมา.
  • ชื่อผู้ใช้: ป้อน รหัสภายนอก หรือ รหัสระบบของบัญชีที่ค้นหา.
    • โปรดทราบว่าหากคุณยังไม่ได้ระบุบัญชีผู้เล่นใด ๆ รายงานจะแสดงข้อมูลของผู้เล่นทั้งหมดในช่วงวันที่เลือก.
  • ถ้าเลือกแสดงการแบ่งกลุ่มในสกุลเงินเดิม: ข้อมูลการแบ่งทุกอย่างจะแสดงในสกุลเงินเดิม มิฉะนั้น ข้อมูลของแถวที่จัดกลุ่มและแถวทั้งหมดจะถูกแปลงเป็นสกุลเงินฐานเสมอ.
  • ไม่รวมข้อมูลการทดสอบ: ไม่รวมตั๋วทั้งหมดจากบัญชีทดสอบ.
    • {CO-productlist-section}
  • การถอนเงินสด: เปิดใช้งานเมื่อคุณเลือกผลิตภัณฑ์การพนันกีฬา.
    • รวมการเงินสดออกในสปอร์ตบุ๊ค: พื้นที่ข้อมูลควรแสดงสปอร์ตบุ๊ครวมถึงตั๋วเงินสดออก.
    • ยกเว้นการเงินสดออกจากการเดิมพันกีฬา: พื้นที่ข้อมูลควรแสดงการเดิมพันกีฬาโดยไม่รวมตั๋วเงินสดออก.
    • ดูเฉพาะการเงินสดทันที: ตัวกรองผลิตภัณฑ์ควรเลือกผลิตภัณฑ์สมุดกีฬาโดยอัตโนมัติและยกเลิกการเลือกผลิตภัณฑ์อื่น ข้อมูลจะได้รับเฉพาะตั๋วเงินสดทันที.
    • {/CO-productlist-section}
  • จัดกลุ่มตาม: จัดข้อมูลในทางต่าง ๆ:
    • ผู้เล่น: แปลงข้อมูลเป็นสกุลเงินหลักและจัดกลุ่มตามผู้เล่น.
      • คอลัมน์ค่าการเดิมพันที่มีประสิทธิภาพจะแสดงบนกลุ่มตามผู้เล่น.
    • ชั่วโมง: แปลงข้อมูลเป็นสกุลเงินพื้นฐานและจัดกลุ่มตามชั่วโมง.
    • วันที่: แปลงข้อมูลเป็นสกุลเงินหลักและจัดกลุ่มตามวันที่.
    • เดือน: แปลงข้อมูลเป็นสกุลเงินฐานและจัดกลุ่มตามเดือน.
    • ผลิตภัณฑ์: แปลงข้อมูลเป็นสกุลเงินหลักและจัดกลุ่มตามผลิตภัณฑ์.
    • กีฬา: แปลงข้อมูลเป็นสกุลเงินหลักและจัดกลุ่มตามกีฬา.
    • ประเภทการเดิมพัน: แปลงข้อมูลเป็นสกุลเงินหลักและจัดกลุ่มตามประเภทการเดิมพัน.
    • สกุลเงิน: แปลงข้อมูลเป็นสกุลเงินฐานและจัดกลุ่มตามสกุลเงิน.
    • แพลตฟอร์ม: แปลงข้อมูลเป็นสกุลเงินฐานและจัดกลุ่มตามแพลตฟอร์ม.
      • {12Bet-licensee-section}
    • ตัวแทน: แปลงข้อมูลเป็นสกุลเงินหลักและจัดกลุ่มตามตัวแทน.
      • {/12Bet-licensee-section}
  • แบ่งตาม: แบ่งข้อมูลตามกลุ่มในวิธี:
    • ผลิตภัณฑ์: เปิดใช้งานเมื่อคุณเลือกจัดกลุ่มตามผู้เล่น/ ชั่วโมง/ วันที่/ เดือน/ สกุลเงิน/ แพลตฟอร์ม.
    • สกุลเงิน: เปิดใช้งานเมื่อคุณเลือกจัดกลุ่มตามชั่วโมง/วันที่/เดือน/ผลิตภัณฑ์/กีฬา/ประเภทการเดิมพัน/แพลตฟอร์ม.
      • {12Bet-licensee-section}
    • ผู้เล่น: เปิดใช้งานเมื่อคุณเลือก Group By Agent เท่านั้น.
      • {/12Bet-licensee-section}

ตัวชี้การรายงาน

  • กลุ่มตาม: ค่าในคอลัมน์จะขึ้นอยู่กับการเลือกกลุ่มตามของคุณ:
    • ผู้เล่น: แสดงระบบ ID และ ID ภายนอก.
      • รหัสระบบ: รหัสลำดับตัวเลขที่สร้างจากระบบของแต่ละบัญชี.
      • รหัสภายนอก: ชื่อผู้ใช้ที่ลงทะเบียนโดยเจ้าของตั๋ว.
    • ชั่วโมง: ตามการเลือกของคุณ รูปแบบคือ: MM/DD/YYYY > HH:MM - HH:MM.
    • วันที่และเดือน: ขึ้นอยู่กับการเลือกของคุณและรูปแบบของมันคือ:
      • วันที่: MM/DD/YYYY
      • เดือน: MM/YYYY
    • ผลิตภัณฑ์, กีฬา, ประเภทการเดิมพัน, สกุลเงิน, และแพลตฟอร์ม: จะแสดงตามที่คุณเลือก.
      • {12Bet-licensee-section}
    • ตัวแทน: แสดงรหัสระบบของตัวแทนทั้งหมดที่มีข้อมูลภายในตัวกรองที่เลือก.
      • {/12Bet-licensee-section}
  • แบ่งตาม: แสดงเมื่อคุณคลิกที่ไอคอนขยายกลุ่มโดย ข้อมูลการแบ่งส่วนจะให้ข้อมูลรายละเอียดเกี่ยวกับข้อมูลกลุ่มโดยเฉพาะ ค่าของคอลัมน์จะขึ้นอยู่กับการเลือกแบ่งตามของคุณ:
    • ผลิตภัณฑ์: ควรแสดงตามที่คุณเลือก.
    • สกุลเงิน: จะแสดงตามที่คุณเลือก.
      • {12Bet-licensee-section}
    • ผู้เล่น: แสดงระบบ ID และ ID ภายนอก.
      • รหัสระบบ: รหัสลำดับตัวเลขที่สร้างจากระบบของแต่ละบัญชี.
      • รหัสภายนอก: ชื่อผู้ใช้ที่ลงทะเบียนโดยเจ้าของตั๋ว.
      • {/12Bet-licensee-section}
  • จำนวนการเดิมพัน: ตั๋วเดิมพันรวมภายในตัวกรองที่เลือก.
  • การหมุนเวียน: การหมุนเวียนของผู้เล่นทั้งหมดภายในตัวกรองที่เลือก.
  • เน็ตเทิร์นโอเวอร์: จำนวนการหมุนเวียนหลังจากหักตั๋วสลากที่ถูกดึงออก.
    • Net Turnover = ยอดเทิร์นโอเวอร์ - ยอดเทิร์นโอเวอร์รวมของตั๋วสลากที่ถูกจับ.
  • ผู้เล่น W/L: จำนวนที่ผู้เล่นชนะหรือแพ้ตามการเดิมพันของพวกเขา.
  • ค่าการเดิมพันที่มีประสิทธิภาพ: ค่าสัมบูรณ์ของผลชนะขาดทุนของผู้เล่นในแต่ละตั๋วเดิมพัน (0 สำหรับการวางเดิมพันที่เสมอและถูกยกเลิก).
  • ผู้เล่น Comm: ค่าคอมมิชชั่นรวมที่นับจากตั๋วเดิมพัน.
  • ผู้รับอนุญาต W/L: จำนวนชนะแพ้ที่ผู้รับอนุญาตได้ตั้งค่ากับผู้เล่น.
    ผู้รับอนุญาต W/L = - (ผู้เล่น W/L)
  • ค่าคอมมิชชั่นของผู้รับอนุญาต: ค่าคอมมิชชั่นที่ผู้รับอนุญาตได้รับจากผลิตภัณฑ์เฉพาะ.
  • ขอบเขต: เปอร์เซ็นต์ของผู้รับอนุญาต WL ที่เกินกว่ายอดเงินเดือนสุทธิ.
    • กำไรสุทธิ = (ผู้รับอนุญาต WL / ยอดเงินเทิร์นโอเวอร์) * 100%

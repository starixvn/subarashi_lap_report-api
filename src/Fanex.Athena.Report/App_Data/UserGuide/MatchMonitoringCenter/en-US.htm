General Info

  • The Match Monitoring Center helps you quickly identify and get alerts for matches that could lead to significant financial losses.
  • This feature currently supports matches with the "Money Line Full Time" bet type only.
  • All times displayed in this function are GMT+8.
  • This report only shows matches that you have specifically added to your monitoring list.

Search Filters

  • League: Use this filter to retrieve monitored matches based on league names.
  • Match: Select the monitored matches that have been added to the monitoring list.
  • Triggered Alert: Use this filter to retrieve monitored matches based on whether any alert rules have been triggered.
  • Currency: Select the currency which data will be retrieved.
    • All: All supported currencies will be listed out.
  • Base Currency: Convert all data to base currency for reference only.
  • Match Status: Using this filter to retrieve monitored matches that have Live or Non-Live tickets.
  • Refresh Timer: Use to control how frequently the page refreshes data automatically.

Report Guidelines

  • Kick Off Time: The match's kickoff time.
  • Match Status: Displays "Live" (with score shown in red) if the match has live bet tickets; otherwise, it shows "Non-Live".
  • Triggered Alert: Indicates whether a match has ever breached any alert rule, regardless of its current status.
    • A green shield icon means the match has never breached any alert rule since being added to the monitoring list.
    • A blinking red alert icon means the match has previously triggered at least one alert rule at any point in time. Clicking the icon opens the alert rule history popup, which provides details of the triggered rules, including detection time, negative forecast amount, stake ratio, and matched rule configuration.
  • Alert Rules: Shows the configured alert rules for the match, or a "-" if none are set.
  • Event: Displays the Home team vs. Away team.
  • Stake %: A pie chart showing the percentage of total stake on the Home (blue) and Away (red) teams. Hovering over a section will show the total stake for that team.
    • Calculations:
      • Stake % Home = [TotalHomeStake / (TotalHomeStake + TotalAwayStake)] * 100
      • Stake % Away = [TotalAwayStake / (TotalHomeStake + TotalAwayStake)] * 100
  • Total Home: Total bets on home team.
    Total Home = Home stake * odds
  • Total Away: Total bets on away team.
    Total Away = Away stake * odds
  • Forecast Home: The amount that Licensee might win/lose if home team/members win.
    Forecast Home = Home stake * odds – away stake
    • A negative number (e.g. -10) indicates Licensee will win if home team wins.
    • A positive number (e.g. 10) indicates Licensee will lose if home team wins.
  • Forecast Away: The amount that Licensee might win/lose if away team/members win.
    Forecast Away = Away stake * odds – home stake
    • A negative number (e.g. -10) indicates Licensee will win if away team wins.
    • A positive number (e.g. 10) indicates Licensee will lose if away team wins.
  • Operation:
    • Setting: A "Setting" link is shown for running matches if you have permissions for Alert Rules or Logs.
    • Remove: Allows you to remove an event from the monitoring list.
  • Gray Rows: These indicate matches that were previously monitored but have now settled. They are for historical review only.

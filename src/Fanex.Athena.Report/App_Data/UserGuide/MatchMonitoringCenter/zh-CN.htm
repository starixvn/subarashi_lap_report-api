一般信息

  • 比赛监控中心可帮助您快速识别并接收可能导致重大财务亏损的比赛警报。
  • 此功能目前仅支持"独赢盘全场"类型的比赛。
  • 本功能中显示的所有时间均为 GMT+8。
  • 本报告仅显示您已特别添加至监控列表的比赛。

搜索过滤器

  • 联赛：使用此筛选器可根据联赛名称筛选已监控的比赛。
  • 赛事：选择已添加至监控列表的比赛。
  • 触发警报：使用此筛选器可根据是否触发警报规则筛选已监控的比赛。
  • 货币：以货币來选择所会列出的数据。
    • 全部：列出所有支持的货币。
  • 基础货币：将所有资料转换为基础货币但仅供参考。
  • 赛事状态：使用此筛选器可筛选拥有直播票或非直播票的已监控比赛。
  • 刷新计时器：用于控制页面自动刷新数据的频率。

报告指南

  • 开赛时间：显示比赛的开赛时间。
  • 比赛状态：若该比赛拥有直播投注票，则显示"直播"（比分以红色显示）；否则显示为"非直播"。
  • 触发警报：表示该比赛自被添加至监控列表以来是否曾违反任何警报规则，不论当前状态为何。
    • 绿色盾牌图标表示该比赛从未触发任何警报规则。
    • 闪烁的红色警报图标表示该比赛曾在某个时间点触发过至少一条警报规则。点击该图标将打开警报规则历史弹窗，显示被触发规则的详细信息，包括侦测时间、负利润预测金额、投注占比以及对应的规则设定。
  • 警报规则：显示该比赛已设定的警报规则，若未设定则显示"-"。
  • 赛事：显示主队 vs 客队。
  • 投注占比：以饼图形式显示投注在主队（蓝色）与客队（红色）上的占比。将鼠标悬停在图表上可查看各队的总投注金额。
    • 计算方式：
      • 主队投注占比 (%) = [主队总投注 / (主队总投注 + 客队总投注)] × 100
      • 客队投注占比 (%) = [客队总投注 / (主队总投注 + 客队总投注)] × 100
  • 主队总计：投注主队的总注单。
    主队总计 = 主队投注额 * 赔率
  • 客队总计：投注客队的总注单。
    客队总计 = 客队投注额 * 赔率
  • 主队预测：预测若是主队获胜，承租公司的输赢金额。
    主队预测 = 主队投注额 * 赔率 - 客队投注额
    • 负数金额 表示若是主队获胜，承租公司将会获胜。
    • 正数金额 表示若是主队获胜，承租公司将不会获胜。
  • 客队预测：预测若是客队获胜，承租公司的输赢金额。
    客队预测 = 客队投注额 * 赔率 - 主队投注额
    • 负数金额 表示若是客队获胜，承租公司将会获胜。
    • 正数金额 表示若是客队获胜，承租公司将不会获胜。
  • 操作：
    • 设定：若您拥有警报规则或日志的权限，并且比赛仍在进行中，则会显示"设定"链接。
    • 移除：可将赛事从监控列表中移除。
  • 灰色行：表示这些比赛已结算，曾经被监控，仅供历史记录查看使用。

General Info

  • The report supports one month viewing data for each submitted time only and data is available from last 3 months up to the current date.
  • This report contains only won/lost/draw tickets.
  • Data can be represented by Daily or Monthly.
  • OANDA Exchange Service will use the exchange rate of the end date of each selected month when converting the figures.

Search Filters

  • Product: selects the Product type as well as Sport types which data will be retrieved.
  • Username: Enter the external ID or system ID of the searched account.
  • Minimum odds: the minimum odds value for bet tickets to be listed out in the report. By default Zero value will be assigned at the beginning
    Note that:
    • Minimum Odds value must be decimal value.
    • The MMR odds are not converted into Decimal Odds.
  • Bet type: select the Bet type of tickets. The list for bet types will correspond to the selected "Sport type".
  • Ticket filter: Data can be filtered by ticket status.
    Notice: for half won/half lost ticket, turnover is half stake of the ticket.

Report Guidelines

  • Date: can be daily or monthly based on your selection and its format is (mm/dd/yyyy).
  • External ID: The username registered by the ticket owner.
  • Currency: the currency to which customer has used to place bet.
  • Sport: the Sport types to which bet ticket belongs.
  • Bet type: the bet types have been bet for each ticket.
  • Total Transaction: number of bet ticket.
  • Turnover: Customer turnover for each bet type.
  • Total Turnover: total Customer turnover.
  • Customer W/L:
    • Win Loss: the amount customer won or lost based on their bets.
    • Comm: total commission counted on bet tickets.
    • Total: Total win/loss amount including commission.
      Total = Win/Loss + Commission

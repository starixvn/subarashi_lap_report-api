General Info

  • Win Loss By Time Zone report displays Licensee win loss by GMT-4 or GMT+8. Note that due to the difference in data conversion, the converted amount (GMT+8) is for reference only.
  • The report contains only won/lost/draw tickets.
  • This report supports up-to-date data. You can filter data up to 3 months per query.
  • A red negative number indicates a loss for Licensee whereas the black positive indicates a win.
    • Licensee Net WL: total win loss amount including commission.
      Licensee Net WL = Licensee WL - Customer Comm + Licensee Comm
    • Margin: percentage of Licensee Net WL over Turnover.
      Margin = (Licensee Net WL/Turnover) * 100%
  • OANDA Exchange Service will use the exchange rate of the end date of each selected month when converting the figures.

Search Filters

  • Time Zone: select time zone in which data is reported.
  • Product: select the product type of bet tickets.
  • Currency: select the currency which data will be retrieved.
  • Base Currency: Convert all data to base currency for reference only.
  • Group By: group data in 2 ways:
    • Product: convert data into a based currency and grouped by product.
    • Currency: group data by currency.
  • Report By: represent data by Daily, Monthly or Summary (based on Product or Currency).
  • Include Draw data: win loss results will include Draw tickets.
  • Convert all figures to Base Currency: convert all data into based currency. This checkbox will be disabled when the data is grouped by product.

Report Guidelines

  • Date/Month: can be daily or monthly based on your Report By selection and its format is:
    - Date: mm/dd/yyyy
    - Month: mm/yyyy
  • Product/Currency: the title of column will be Product or Currency based on your Group By selection.
  • Bet Count: total bet tickets of selected products.
  • Turnover: total customer betting amount.
  • Customer Comm: commission given to customers based on their commission settings.
  • Licensee WL: the win loss amount Licensee has settled with customer.
  • Licensee Comm: commission that Licensee received from specific products.

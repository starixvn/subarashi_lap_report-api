General Info

  • The report contains only Promotion Prize, Jackpot Contribution, Jackpot Prize, Tip, Bonus, Free Bets and Lucky Draw tickets.
  • This report supports up-to-date data. You can filter data up to 3 months per query.
  • A red negative number indicates a loss for Licensee whereas the black positive indicates a win.
  • OANDA Exchange Service will use the exchange rate of the end date of each selected month when converting the figures.

Search Filters

  • Report by: Data can be represented by Daily or Monthly.
  • Exclude Test Data: Excludes all tickets from test account.
  • Product: Select products having Promotion Prize, Jackpot Contribution, Jackpot Prize, Tip, Bonus, Free Bets and Lucky Draw tickets.
  • Promotion Type: Select promotion types of each product.
  • Currency: Selects the currency which data will be retrieved.
    • All: All supported currencies of will be listed out.
  • Base Currency: Convert all data to base currency for reference only.
  • Convert all figures to Base Currency: Convert all data into base currency. Otherwise, data of currency row will be in original currency and data of Total rows will be always converted into base currency.

Report Guidelines

  • Date: Can be daily or monthly based on your selection and its format is (mm/dd/yyyy).
  • Currency: Offered currency has been selected by yours. To view in detail click on each currency.
  • Product: The selected products have Promotion Prize, Jackpot Contribution, Jackpot Prize, Tip, Bonus, Free Bets and Lucky Draw tickets.
  • Promotion Type: The selected promotion type of each product.
  • Turnover: Total customer turnover of the tickets within a selected date range.
  • Total Transaction: Total bet tickets within a selected date range.
  • Customer Amount: The amount customer has based on the promotions.
  • Licensee Sharing Amount: The amount Licensee has based on the promotions.

General Info

  • The report displays the win loss amount for different betting products within a selected date range.
  • This report supports up-to-date data.
  • Any query before 4PM GMT-4 will return the data up to 4PM of the day before. You can filter data up to 1 month per query. 
  • This report contains only won/lost/draw tickets of Live matches.
  • OANDA Exchange Service will use the exchange rate of the end date of each selected month when converting the figures.

Search Filters

  • Currency: selects the currency which data will be retrieved.
    • All: all supported currencies will be listed out.
  • Base Currency: Convert all data to base currency for reference only.

Report Guidelines

  • Product: the list of products having data within the selected date range. For more detail win loss, click on each product type.
    Note that detail data drilling down from sport types are only available from {balance-up-date}.
  • Customer W/L:
    • Win Loss: the amount customer won or lost based on their bets.
    • Comm: total commission counted on bet tickets.
    • Total: Total win/loss amount including commission.
      Total = Win/Loss + Commission
  • Turnover: total Customer turnover.
  • Bet Count: total bet tickets of selected products.
  • Licensee W/L: the win loss amount Licensee has settled with Customer.
    Licensee Win/Loss = – (Customer Win/Loss)
  • Comm: Total Licensee commission received from each Product.
